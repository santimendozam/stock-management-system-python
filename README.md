# 📦 Stock Management System

A console-based inventory manager built in Python as a hands-on practice project.

---

## 📋 Features

- View current inventory
- Add products with name and price
- Delete products
- Edit existing product prices
- Input validation throughout (empty fields, invalid prices, missing products)
- Paraguayan price format support (e.g. `20.000`)

## 🚀 How to run
```bash
python stock.py
```

No external libraries required — runs on pure Python 3.
